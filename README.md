# ABOUT

aptのログを見やすく簡略化するためのやつ。ほとんど個人用の上、8割をAIに書かせてそこに私が手を加えたゴミみたいなソースコードのため、使用は自己責任です。

`/var/log/apt/` に含まれる`history.log*`ファイル群を取り込んで見やすくフォーマット化して出力するだけの仕組みです。

動作環境は... 多分aptあるなら動くんじゃない？知らんけど。一応Ubuntu24.04で動きます多分。

そもそもこれを使う人はいるのか...?

# HOW TO USE

`asl.py`をシェルスクリプトみたいな感じで動かすだけです。sudoで動かしたほうがいいかも
```
$ sudo ./asl.py
```
<br>

一応サブコマンドもあります。
```
$ sudo ./asl.py simple
```

サブコマンドの`simple`は、OSインストール時に自動でaptが入れてくれるパッケージとかの表示を除去します。<br>
実行されたaptコマンドに`AutoInstall=yes`の文字列を検知するとその部分を間引く仕組み。

あとはパイプでもなんでもつなげて自由に使いましょう。
